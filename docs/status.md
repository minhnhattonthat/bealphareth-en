- **Key facts:** text is a custom mode-shifted 1/2-byte code in `M4`/`M2` banks, 61,794 strings / 2.8 MB. The font is **MS Gothic 12 px cropped to 11x11**: 1,513 of 1,909 distinct cells match a modern MS Gothic render bit for bit, so glyph OCR is automatic (`tbl/glyphs.tsv`). Base kanji font at `PSX.EXE` 0x17CE0 (896 cells, `(hi-0x80)*112+(lo-0x80)`); a scene's M4 part 0 is its own glyph bank (`E0`+ codes, `(hi-0xE0)*112+(lo-0x80)`), shared by every M2 bank in that overlay. One-byte fonts: ASCII at 0x16B90, hiragana at 0x17250, katakana at 0x17780 (custom pixel kana, not MS Gothic). Map jump is `MAIN.EXE` 0x80029838 through the request block at 0x80097B28 (+0xC map, +0xE entrance); the debug menu still exists (set `0x1C2(gp)`=1, then R2+Cross).
